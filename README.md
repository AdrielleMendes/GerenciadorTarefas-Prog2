
# To-Do List | Gerenciador de Tarefas

Projeto prático desenvolvido para a disciplina de **Programação 2** na **Universidade Federal Rural de Pernambuco (UFRPE/UABJ)**, sob orientação do **Prof. Anderson Cavalcanti**.

##  Sobre o Projeto
O objetivo deste software é aplicar os conceitos fundamentais de **Programação Orientada a Objetos (POO)** em Java. O sistema permite que o usuário gerencie suas atividades diárias através de um terminal interativo, controlando prazos, prioridades e status de conclusão.

## 🛠️ Funcionalidades
- **Cadastro de Tarefas:** Adição de título, descrição, prazo e nível de prioridade.
- **Gerenciamento de Status:** Opção para marcar tarefas como concluídas ou pendentes.
- **Listagem Dinâmica:** Visualização completa de todas as tarefas cadastradas.
- **Filtros:** Opção para visualizar apenas as tarefas que ainda não foram realizadas.
- **Remoção:** Exclusão de itens da lista através do índice.

##  Estrutura do Projeto (POO)
O código está organizado em pacotes para garantir a separação de responsabilidades:

- `model`: Contém a classe **Tarefa**, que define os atributos e o estado do objeto.
- `service`: Contém a classe **Gerenciador**, responsável pela lógica de manipulação do `ArrayList` e regras de negócio.
- `view`: Contém a classe **Main**, que gerencia a interface de usuário e o menu de interação via console.
